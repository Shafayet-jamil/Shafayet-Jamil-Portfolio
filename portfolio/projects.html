Smart Pond — Digital Twin Pond Manager

Flutter app (Android + web dashboard) for small fish ponds in Bangladesh. It connects to an ESP32 pond node over MQTT and keeps a digital twin of the pond.

  • Live DO, pH, TDS, turbidity, temperature and water level
  • Multi-sensor anomaly detection with “possible contamination” alerts
  • Aerator and feeder control, daily PDF report in Bengali and English
Flutter Dart MQTT ESP32 IoT

MediChecker

Flutter mobile app with a Python Flask API for checking medicines.

  • Reads a medicine package photo with OCR (EasyOCR)
  • Looks up a medicine by its DAR / MA registration number
  • Checks selected medicines for drug interactions (optional DDInter data, ~160,000 pairs)
Flutter Python Flask EasyOCR

Telecom Churn-Risk Prediction

GCI World 2026 final assignment: predict which customers of a wireless operator will leave, and who should get a retention offer.

  • Data quality checks, EDA and feature engineering on 100,000 customers
  • Logistic regression vs LightGBM, XGBoost and CatBoost with 5-fold CV; best test ROC-AUC 0.709
  • Expected-value targeting rule with sensitivity analysis
Python pandas scikit-learn LightGBM XGBoost
